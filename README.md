# Rental Car Management System

Final Project for **CCS0015L – Data Structures and Algorithms**

## Project Overview

The Rental Car Management System is a C++ console application designed to manage vehicle rentals. It allows users to maintain vehicle and customer records, process rentals and returns, and store information using text files.

The project demonstrates the application of Data Structures and Algorithms concepts required in CCS0015L.

---

## Features

- Display all cars
- Display available cars
- Add new car
- Remove car
- Search car by ID (Binary Search)
- Search car by brand (Linear Search)
- Sort cars by daily rate (Bubble Sort)
- Sort cars by brand (Selection Sort)
- Display customers
- Add customer
- Rent a car
- Return a car
- Display active rentals
- Display transaction history
- Initialize demo data
- Display system statistics

---

## Data Structures Used

- Linked List
  - Stores vehicle records

- Vector
  - Stores customer records
  - Stores customer rental history

- Queue
  - Stores active rental transactions

- Stack
  - Stores transaction history

- List
  - Tracks vehicle IDs

---

## Algorithms Used

- Bubble Sort
  - Sort vehicles by daily rental rate

- Selection Sort
  - Sort vehicles alphabetically by brand

- Linear Search
  - Search vehicles by brand

- Binary Search
  - Search vehicles by Car ID
